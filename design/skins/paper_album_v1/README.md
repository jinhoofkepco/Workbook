# Paper Album v1

`paper_album_v1`은 문제집 선택 화면을 책장/앨범처럼 보이게 만드는 기본 스킨 템플릿입니다.

작업 순서:

1. `prompts.md`의 각 프롬프트로 이미지를 생성합니다.
2. 생성한 PNG를 `assets/` 폴더에 파일명 그대로 넣습니다.
3. 큰 배경 이미지는 앱 UI보다 약하게 보이도록 대비/불투명도를 조정합니다.
4. PNG 메타데이터를 제거하고 용량을 줄입니다. 예: `oxipng -o 4 --strip all assets/*.png`
5. 버튼/스탬프/팝업 계열은 투명 배경이 유지되는지 확인합니다.
6. `skin.json`과 `assets/` 폴더를 함께 ZIP으로 묶습니다.
7. ZIP 파일명은 `workbook_skin_paper_album_v1.zip`을 권장합니다.

앱에 스킨 import 기능을 붙일 때는 `skin.json`의 `assets` 경로를 기준으로 로드하면 됩니다.

생성 이미지 검수 기준:

- 앱 텍스트, 문제 이미지, 답 입력칸보다 스킨 장식이 먼저 보이면 실패입니다.
- 학생용 하단 진도/문제 메뉴는 제거되었습니다. 하단 그래픽은 마스터 `마` 버튼 프레임처럼 지정된 곳에만 적용합니다.
- 책 표지에는 앱이 그리는 진행률 배지와 진행률 선이 올라갈 자리를 비워 둡니다.
- 책꽂이 화면의 상용 앱 느낌은 `dashboard_page_frame_1600x2400.png`, `dashboard_title_frame_1000x180.png`, `book_shelf_band_1600x260.png` 같은 작은 투명 오버레이로 강화합니다. 큰 배경 이미지를 여러 장 만들지 않습니다.
- 문제집 선택 제목 배너, 문제 화면 헤더, 이전/다음, 힌트, 제출 버튼용 그래픽 안에는 글자/숫자를 절대 넣지 않습니다. 앱이 텍스트를 얹습니다.
- 단원 행 배경은 제목 시작 위치에 진한 색 경계가 생기지 않도록 최대한 밋밋하게 만듭니다.
- `dashboard_bg_1600x2560.png`와 `problem_paper_bg_1600x2560.png`는 종이 노이즈를 줄여 PNG 용량을 낮춥니다.
